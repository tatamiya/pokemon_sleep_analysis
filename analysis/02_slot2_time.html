固定確率・1変化点・滑らかな時間変化

この分析の位置づけ

analysis/01_probability.qmd では、全期間をまとめた2枠目Aの出現割合が、 通説上の確率 \(1/3\) より低いという結果が得られた。

ここで新たに調べたい主な問いは、2枠目Aの出現確率が時間によらず一定とみなせるかである。 比較の基準には、全期間で一つの未知の確率を共有する一定モデルを用いる。

\[ M_1: p_t = p \]

通説値 \(p=1/3\) との比較はPart 1で扱ったため、 この分析の中心は \(M_1\) と時間変化モデルの比較に置く。 通説値との比較は、最後に補足として掲載する。

本記事の主分析では、全期間で確率が一定の \(M_1\) と、 期間中に1回だけ確率が変わる1変化点モデル \(M_3\) を比較する。 変化点は事前に3月などへ固定せず、候補範囲から推定する。 ただし、急変ではなく緩やかに変化した可能性もあるため、 滑らかな時間変化モデル \(M_2\) と \(M_1\) の比較も補足的に行う。 \(M_2\) と \(M_3\) の直接比較は主目的としない。

以下では記事と同じく、基本確認、1変化点モデル \(M_3\)、 滑らかな時間変化モデル \(M_2\)、1変化点検定の検出力の順に示す。

日次集計

同じ日に得られた観測は、日次の二項データとしてまとめる。

\[ A_d \sim \operatorname{Binomial}(n_d,p_d) \]

同じ日の各観測が共通の \(p_d\) を持ち、条件付きで独立なら、 個々のBernoulliデータを使う場合と日次集計を使う場合の尤度は本質的に同じである。 ただし、日次集計によって同日内の依存性が解消されるわけではない。

コードを表示 
daily_slot2 <- slot2_data %>%
  group_by(日付) %>%
  summarise(
    A出現数 = sum(A指標),
    B出現数 = sum(1L - A指標),
    試行数 = n(),
    A出現割合 = A出現数 / 試行数,
    .groups = "drop"

daily_calendar <- tibble(

基準となる一定モデル

モデル

日次のBinomialデータに対して、全期間でAの出現確率が一定のモデルを当てはめる。

\[ M_1: A_d \sim \operatorname{Binomial}(n_d,p), \qquad p\text{は未知} \]

\(p\) は通説値の \(1/3\) に固定せず、全期間のデータから推定する。 以降の時間変化モデルも同じ日次Binomial尤度を使う。

1変化点モデル

モデル

境界が未知の1変化点モデルを、次のように定義する。

\[ M_3: A_d \sim \operatorname{Binomial}(n_d,p_d), \]

\[ p_d= \begin{cases} p_1 & t_d < \tau,\\ p_2 & t_d \geq \tau. \end{cases} \]

変化点 \(\tau\) は、連続する観測日の間だけを候補とする。 観測がない日のどこに境界を置いても尤度は同じなので、 観測日の間をさらに細分化しない。

端に近い不安定な分割を避けるため、前後それぞれに全試行数の20%以上が含まれる候補だけを使用する。 20%という候補範囲は、Aの出現結果を用いて変更しない。

各候補の最尤推定と日次Binomial尤度

日次Binomial対数尤度は、日ごとの二項係数とBernoulli対数尤度核に分けられる。 同じ日次データを比較する限り二項係数はすべてのモデルで共通だが、 実データの絶対尤度には日次の二項係数も含める。

コードを表示 
# Binomial確率の最尤値 p = x / n における、
# 二項係数を除いた対数尤度を返す。
# x = 0またはx = nの場合も0 log(0)を0として扱う。
binomial_mle_log_kernel <- function(
  successes,
  trials
) {
  probability <- successes / trials
  failures <- trials - successes
  result <- successes * 0

  positive_successes <- successes > 0
  result[positive_successes] <-
    successes[positive_successes] *
      log(probability[positive_successes])

  positive_failures <- failures > 0
  result[positive_failures] <-
    result[positive_failures] +
      failures[positive_failures] *
        log1p(-probability[positive_failures])

  result
}

calculate_max_m1_m3_statistic_for_candidates <- function(
  a_count,
  candidate_positions,
  candidate_pre_trials,
  candidate_post_trials
) {
  cumulative_a_count <- cumsum(a_count)
  total_a_count <- sum(a_count)

  candidate_pre_a_count <- cumulative_a_count[
    candidate_positions
  ]

  candidate_post_a_count <-
    total_a_count -
      candidate_pre_a_count

  log_kernel_m1 <- binomial_mle_log_kernel(
    successes = total_a_count,
    trials = total_trials_m3
  )

  log_kernel_m3 <-
    binomial_mle_log_kernel(
      successes = candidate_pre_a_count,
      trials = candidate_pre_trials
    ) +
    binomial_mle_log_kernel(
      successes = candidate_post_a_count,
      trials = candidate_post_trials
    )

  max(
    2 * (
      log_kernel_m3 -
        log_kernel_m1
    )
  )
}

evaluate_change_point_range_m3 <- function(
  minimum_fraction
) {
  minimum_trials <- ceiling(
    minimum_fraction * total_trials_m3
  )

  candidate_profile <- daily_slot2 %>%
    arrange(日付) %>%
    mutate(
      日次位置 = row_number(),
      変化点直前観測日 = 日付,
      変化点直後観測日 = lead(日付),
      前観測数 = cumsum(試行数),
      前A出現数 = cumsum(A出現数),
      後観測数 = total_trials_m3 - 前観測数,
      後A出現数 = total_a_m3 - 前A出現数
    ) %>%
    filter(
      !is.na(変化点直後観測日),
      前観測数 >= minimum_trials,
      後観測数 >= minimum_trials
    ) %>%
    mutate(
      前A推定確率 = 前A出現数 / 前観測数,
      後A推定確率 = 後A出現数 / 後観測数,
      M1からの尤度比改善量 = 2 * (
        binomial_mle_log_kernel(
          successes = 前A出現数,
          trials = 前観測数
        ) +
          binomial_mle_log_kernel(
            successes = 後A出現数,
            trials = 後観測数
          ) -
          binomial_mle_log_kernel(
            successes = total_a_m3,
            trials = total_trials_m3
          )
      )
    )

  best_candidate <- candidate_profile %>%
    slice_max(
      order_by = M1からの尤度比改善量,
      n = 1,
      with_ties = FALSE
    )

  set.seed(bootstrap_seed_m3)

  bootstrap_statistic <- map_dbl(
    seq_len(bootstrap_repetitions_m3),
    function(i) {
      simulated_a_count <- rbinom(
        n = nrow(daily_slot2),
        size = daily_slot2$試行数,
        prob = p_m1
      )

      calculate_max_m1_m3_statistic_for_candidates(
        a_count = simulated_a_count,
        candidate_positions =
          candidate_profile$日次位置,
        candidate_pre_trials =
          candidate_profile$前観測数,
        candidate_post_trials =
          candidate_profile$後観測数
      )
    }
  )

  bootstrap_p_value <- (
    sum(
      bootstrap_statistic >=
        best_candidate$M1からの尤度比改善量
    ) + 1
  ) / (
    bootstrap_repetitions_m3 + 1
  )

  best_candidate %>%
    transmute(
      最小セグメント割合 = minimum_fraction,
      前後それぞれの最小観測数 = minimum_trials,
      候補変化点数 = nrow(candidate_profile),
      最尤変化点区間 = paste0(
        変化点直前観測日,
        " ～ ",
        変化点直後観測日
      ),
      前観測数,
      後観測数,
      前A出現割合 = 前A推定確率,
      後A出現割合 = 後A推定確率,
      最大尤度比改善量 =
        M1からの尤度比改善量,
      ブートストラップp値 =
        bootstrap_p_value
    )
}

滑らかな時間変化モデル

モデル

滑らかな時間変化モデルを、二項GAMとして定義する。

\[ M_2: A_d \sim \operatorname{Binomial}(n_d,p_d), \qquad \operatorname{logit}(p_d)=\beta_0+f(t_d) \]

\(f(t)\) にはthin plate regression splineを使用する。 基底次元は \(k=10\) に固定し、平滑化パラメータはREMLで推定する。 低下方向や単調性は仮定しない。

bootstrap_seed_m2 <- 20260824L

calculate_m1_m2_statistic <- function(
  a_count,
  trial_count,
  elapsed_day
) {
  bootstrap_data <- tibble(
    A出現数 = a_count,
    B出現数 = trial_count - a_count,
    試行数 = trial_count,
    経過日 = elapsed_day
  )

  bootstrap_m1 <- glm(
    cbind(A出現数, B出現数) ~ 1,
    family = binomial(),
    data = bootstrap_data
  )

  bootstrap_m2 <- gam(
    cbind(A出現数, B出現数) ~
      s(
        経過日,
        bs = "tp",
        k = 10
      ),
    family = binomial(),
    method = "REML",
    data = bootstrap_data
  )

  bootstrap_log_lik_m1 <- daily_binomial_log_lik(
    data = bootstrap_data,
    prob = fitted(bootstrap_m1)
  )

  bootstrap_log_lik_m2 <- daily_binomial_log_lik(
    data = bootstrap_data,
    prob = fitted(bootstrap_m2)
  )

  2 * (
    bootstrap_log_lik_m2 -
      bootstrap_log_lik_m1
  )
}

第4段階：1変化点検定の検出力

目的と解釈上の注意

ここでは、実際に1回の確率変化が存在したと仮定したとき、 現在の 360 観測と第2段階の検定手順で、 その変化をどの程度検出できるかをsimulationで評価する。

この検出力分析は、次の点に注意して解釈する。

  1. 「\(M_3\) が正しい確率」を求める分析ではない。
  2. 指定した大きさの変化が本当に存在した場合に、現在の検定手順がそれを検出する割合を評価する。
  3. シナリオ2の \(p_1\)、\(p_2\) は、実データから最尤変化点を探索した後に得られた値である。winner’s curseの可能性があるため、真の効果量の強い推定値ではなく参考シナリオとして扱う。
  4. 主な解釈では、事前に意味を定めやすい \(p_1=1/3\)、\(p_2=1/4\) のシナリオを重視する。
  5. 今回の分析全体は時系列グラフを見たことをきっかけに始めた探索的分析であり、検出力分析を加えてもその探索性は消えない。

検出力simulationでも、観測日、日ごとの試行数、 161 個の候補変化点、 各候補での最尤推定、最大尤度比統計量の計算を第2段階と同じにする。 真の変化点はデータ生成にだけ使用し、検定アルゴリズムには与えない。

estimate_m3_detection_power <- function(
  p1,
  p2,
  true_daily_position,
  repetitions,
  simulation_seed
) {
  stopifnot(
    p1 >= 0,
    p1 <= 1,
    p2 >= 0,
    p2 <= 1,
    true_daily_position >= 1,
    true_daily_position < nrow(daily_slot2)
  )

  true_probability_by_day <- if_else(
    seq_len(nrow(daily_slot2)) <=
      true_daily_position,
    p1,
    p2
  )

  set.seed(simulation_seed)

  simulated_max_statistic <- map_dbl(
    seq_len(repetitions),
    function(i) {
      simulated_a_count <- rbinom(
        n = nrow(daily_slot2),
        size = daily_slot2$試行数,
        prob = true_probability_by_day
      )

      calculate_max_m1_m3_statistic(
        a_count = simulated_a_count
      )
    }
  )

  detected <- simulated_max_statistic >=
    critical_value_m3

  estimated_power <- mean(detected)

  tibble(
    p1 = p1,
    p2 = p2,
    真の変化点日次位置 = true_daily_position,
    simulation回数 = repetitions,
    検出成功回数 = sum(detected),
    推定検出力 = estimated_power,
    Monte_Carlo標準誤差 = sqrt(
      estimated_power *
        (1 - estimated_power) /
        repetitions
    ),
    simulation_seed = simulation_seed
  )
}

# この分析の位置づけ

`analysis/01_probability.qmd` では、全期間をまとめた2枠目Aの出現割合が、
通説上の確率 $1/3$ より低いという結果が得られた。

ここで新たに調べたい主な問いは、2枠目Aの出現確率が時間によらず一定とみなせるかである。
比較の基準には、全期間で一つの未知の確率を共有する一定モデルを用いる。

$$
M_1: p_t = p
$$

通説値 $p=1/3$ との比較はPart 1で扱ったため、
この分析の中心は $M_1$ と時間変化モデルの比較に置く。
通説値との比較は、最後に補足として掲載する。

本記事の主分析では、全期間で確率が一定の $M_1$ と、
期間中に1回だけ確率が変わる1変化点モデル $M_3$ を比較する。
変化点は事前に3月などへ固定せず、候補範囲から推定する。
ただし、急変ではなく緩やかに変化した可能性もあるため、
滑らかな時間変化モデル $M_2$ と $M_1$ の比較も補足的に行う。
$M_2$ と $M_3$ の直接比較は主目的としない。

以下では記事と同じく、基本確認、1変化点モデル $M_3$、
滑らかな時間変化モデル $M_2$、1変化点検定の検出力の順に示す。

# 基準となる一定モデル

## モデル

日次のBinomialデータに対して、全期間でAの出現確率が一定のモデルを当てはめる。

$$
M_1: A_d \sim \operatorname{Binomial}(n_d,p),
\qquad p\text{は未知}
$$

$p$ は通説値の $1/3$ に固定せず、全期間のデータから推定する。
以降の時間変化モデルも同じ日次Binomial尤度を使う。

# 1変化点モデル

## モデル

境界が未知の1変化点モデルを、次のように定義する。

$$
M_3:
A_d \sim \operatorname{Binomial}(n_d,p_d),
$$

$$
p_d=
\begin{cases}
p_1 & t_d < \tau,\\
p_2 & t_d \geq \tau.
\end{cases}
$$

変化点 $\tau$ は、連続する観測日の間だけを候補とする。
観測がない日のどこに境界を置いても尤度は同じなので、
観測日の間をさらに細分化しない。

端に近い不安定な分割を避けるため、前後それぞれに全試行数の20%以上が含まれる候補だけを使用する。
20%という候補範囲は、Aの出現結果を用いて変更しない。

## 各候補の最尤推定と日次Binomial尤度

日次Binomial対数尤度は、日ごとの二項係数とBernoulli対数尤度核に分けられる。
同じ日次データを比較する限り二項係数はすべてのモデルで共通だが、
実データの絶対尤度には日次の二項係数も含める。

```{r}
#| label: profile-change-point-likelihood

# Binomial確率の最尤値 p = x / n における、
# 二項係数を除いた対数尤度を返す。
# x = 0またはx = nの場合も0 log(0)を0として扱う。
binomial_mle_log_kernel <- function(
  successes,
  trials
) {
  probability <- successes / trials
  failures <- trials - successes
  result <- successes * 0

  positive_successes <- successes > 0
  result[positive_successes] <-
    successes[positive_successes] *
      log(probability[positive_successes])

  positive_failures <- failures > 0
  result[positive_failures] <-
    result[positive_failures] +
      failures[positive_failures] *
        log1p(-probability[positive_failures])

  result
}

daily_binomial_constant_m3 <- sum(
  lchoose(
    daily_slot2$試行数,
    daily_slot2$A出現数
  )
)

log_lik_m1_from_kernel <-
  daily_binomial_constant_m3 +
    binomial_mle_log_kernel(
      successes = total_a_m3,
      trials = total_trials_m3
    )

stopifnot(
  isTRUE(
    all.equal(
      log_lik_m1,
      log_lik_m1_from_kernel,
      tolerance = 1e-10
    )
  )
)
```

## パラメトリック・ブートストラップ

$M_1$ のもとで、元データと同じ観測日・日ごとの試行数を保ったデータを生成する。
各反復でも実データと同じ候補変化点をすべて探索し、

```{r}
#| label: bootstrap-m1-m3

bootstrap_repetitions_m3 <- 2000L
bootstrap_seed_m3 <- 20260825L

candidate_daily_positions_m3 <-
  change_point_profile_m3$日次位置

candidate_pre_trials_m3 <-
  change_point_profile_m3$前観測数

candidate_post_trials_m3 <-
  change_point_profile_m3$後観測数

calculate_max_m1_m3_statistic_for_candidates <- function(
  a_count,
  candidate_positions,
  candidate_pre_trials,
  candidate_post_trials
) {
  cumulative_a_count <- cumsum(a_count)
  total_a_count <- sum(a_count)

  candidate_pre_a_count <- cumulative_a_count[
    candidate_positions
  ]

  candidate_post_a_count <-
    total_a_count -
      candidate_pre_a_count

  log_kernel_m1 <- binomial_mle_log_kernel(
    successes = total_a_count,
    trials = total_trials_m3
  )

  log_kernel_m3 <-
    binomial_mle_log_kernel(
      successes = candidate_pre_a_count,
      trials = candidate_pre_trials
    ) +
    binomial_mle_log_kernel(
      successes = candidate_post_a_count,
      trials = candidate_post_trials
    )

  max(
    2 * (
      log_kernel_m3 -
        log_kernel_m1
    )
  )
}

calculate_max_m1_m3_statistic <- function(
  a_count
) {
  calculate_max_m1_m3_statistic_for_candidates(
    a_count = a_count,
    candidate_positions =
      candidate_daily_positions_m3,
    candidate_pre_trials =
      candidate_pre_trials_m3,
    candidate_post_trials =
      candidate_post_trials_m3
  )
}

set.seed(bootstrap_seed_m3)

bootstrap_max_statistic_m3 <- map_dbl(
  seq_len(bootstrap_repetitions_m3),
  function(i) {
    simulated_a_count <- rbinom(
      n = nrow(daily_slot2),
      size = daily_slot2$試行数,
      prob = p_m1
    )

    calculate_max_m1_m3_statistic(
      a_count = simulated_a_count
    )
  }
)

p_bootstrap_m1_m3 <- (
  sum(
    bootstrap_max_statistic_m3 >=
      maximum_lr_m1_m3

) / (

)

mcse_bootstrap_m1_m3 <- sqrt(
  p_bootstrap_m1_m3 *
    (1 - p_bootstrap_m1_m3) /
    (bootstrap_repetitions_m3 + 1)
)
```

## 候補範囲の感度分析

主分析では、期間端の不安定な分割を避けるため、
変化点の前後それぞれに全観測の20%以上が残る候補だけを使用した。
この20%という設定への依存を確認するため、15%と25%でも同じ分析を行う。
それぞれの設定で候補を作り直し、各ブートストラップ反復でも、
対応する候補をすべて探索する。

```{r}
#| label: sensitivity-change-point-range

sensitivity_segment_fractions_m3 <- c(
  0.15,
  0.20,
  0.25
)

evaluate_change_point_range_m3 <- function(
  minimum_fraction
) {
  minimum_trials <- ceiling(
    minimum_fraction * total_trials_m3
  )

  candidate_profile <- daily_slot2 %>%
    arrange(日付) %>%
    mutate(
      日次位置 = row_number(),
      変化点直前観測日 = 日付,
      変化点直後観測日 = lead(日付),
      前観測数 = cumsum(試行数),
      前A出現数 = cumsum(A出現数),
      後観測数 = total_trials_m3 - 前観測数,
      後A出現数 = total_a_m3 - 前A出現数
    ) %>%
    filter(
      !is.na(変化点直後観測日),
      前観測数 >= minimum_trials,
      後観測数 >= minimum_trials
    ) %>%
    mutate(
      前A推定確率 = 前A出現数 / 前観測数,
      後A推定確率 = 後A出現数 / 後観測数,
      M1からの尤度比改善量 = 2 * (
        binomial_mle_log_kernel(
          successes = 前A出現数,
          trials = 前観測数
        ) +
          binomial_mle_log_kernel(
            successes = 後A出現数,
            trials = 後観測数
          ) -
          binomial_mle_log_kernel(
            successes = total_a_m3,
            trials = total_trials_m3
          )
      )
    )

  best_candidate <- candidate_profile %>%
    slice_max(
      order_by = M1からの尤度比改善量,
      n = 1,
      with_ties = FALSE
    )

  set.seed(bootstrap_seed_m3)

  bootstrap_statistic <- map_dbl(
    seq_len(bootstrap_repetitions_m3),
    function(i) {
      simulated_a_count <- rbinom(
        n = nrow(daily_slot2),
        size = daily_slot2$試行数,
        prob = p_m1
      )

      calculate_max_m1_m3_statistic_for_candidates(
        a_count = simulated_a_count,
        candidate_positions =
          candidate_profile$日次位置,
        candidate_pre_trials =
          candidate_profile$前観測数,
        candidate_post_trials =
          candidate_profile$後観測数
      )
    }
  )

  bootstrap_p_value <- (
    sum(
      bootstrap_statistic >=
        best_candidate$M1からの尤度比改善量
    ) + 1
  ) / (
    bootstrap_repetitions_m3 + 1
  )

  best_candidate %>%
    transmute(
      最小セグメント割合 = minimum_fraction,
      前後それぞれの最小観測数 = minimum_trials,
      候補変化点数 = nrow(candidate_profile),
      最尤変化点区間 = paste0(
        変化点直前観測日,
        " ～ ",
        変化点直後観測日
      ),
      前観測数,
      後観測数,
      前A出現割合 = 前A推定確率,
      後A出現割合 = 後A推定確率,
      最大尤度比改善量 =
        M1からの尤度比改善量,
      ブートストラップp値 =
        bootstrap_p_value
    )
}
```

# 滑らかな時間変化モデル

## モデル

滑らかな時間変化モデルを、二項GAMとして定義する。

$$
M_2:
A_d \sim \operatorname{Binomial}(n_d,p_d),
\qquad
\operatorname{logit}(p_d)=\beta_0+f(t_d)
$$

$f(t)$ にはthin plate regression splineを使用する。
基底次元は $k=10$ に固定し、平滑化パラメータはREMLで推定する。
低下方向や単調性は仮定しない。

```{r}

bootstrap_seed_m2 <- 20260824L

calculate_m1_m2_statistic <- function(
  a_count,
  trial_count,
  elapsed_day
) {
  bootstrap_data <- tibble(
    A出現数 = a_count,
    B出現数 = trial_count - a_count,
    試行数 = trial_count,
    経過日 = elapsed_day
  )

  bootstrap_m1 <- glm(
    cbind(A出現数, B出現数) ~ 1,
    family = binomial(),
    data = bootstrap_data
  )

  bootstrap_m2 <- gam(
    cbind(A出現数, B出現数) ~
      s(
        経過日,
        bs = "tp",
        k = 10
      ),
    family = binomial(),
    method = "REML",
    data = bootstrap_data
  )

  bootstrap_log_lik_m1 <- daily_binomial_log_lik(
    data = bootstrap_data,
    prob = fitted(bootstrap_m1)
  )

  bootstrap_log_lik_m2 <- daily_binomial_log_lik(
    data = bootstrap_data,
    prob = fitted(bootstrap_m2)
  )

  2 * (
    bootstrap_log_lik_m2 -
      bootstrap_log_lik_m1
  )
}

      size = daily_m2_data$試行数,
      prob = p_m1
    )

    tryCatch(
      calculate_m1_m2_statistic(

        trial_count = daily_m2_data$試行数,
        elapsed_day = daily_m2_data$経過日
      ),
```

# 第4段階：1変化点検定の検出力

## 目的と解釈上の注意

ここでは、実際に1回の確率変化が存在したと仮定したとき、
現在の `r n_slot2` 観測と第2段階の検定手順で、
その変化をどの程度検出できるかをsimulationで評価する。

この検出力分析は、次の点に注意して解釈する。

1. 「$M_3$ が正しい確率」を求める分析ではない。
2. 指定した大きさの変化が本当に存在した場合に、現在の検定手順がそれを検出する割合を評価する。
3. シナリオ2の $p_1$、$p_2$ は、実データから最尤変化点を探索した後に得られた値である。winner's curseの可能性があるため、真の効果量の強い推定値ではなく参考シナリオとして扱う。
4. 主な解釈では、事前に意味を定めやすい $p_1=1/3$、$p_2=1/4$ のシナリオを重視する。
5. 今回の分析全体は時系列グラフを見たことをきっかけに始めた探索的分析であり、検出力分析を加えてもその探索性は消えない。

検出力simulationでも、観測日、日ごとの試行数、
`r nrow(change_point_candidates_m3)` 個の候補変化点、
各候補での最尤推定、最大尤度比統計量の計算を第2段階と同じにする。
真の変化点はデータ生成にだけ使用し、検定アルゴリズムには与えない。

## 棄却臨界値

第2段階で $M_1$ から生成した最大尤度比統計量の95%点を、
有意水準5%の棄却臨界値とする。

$$
c_\alpha=\operatorname{quantile}
\left(
T_{\max}^{(M_1)},
0.95
\right).
$$

```{r}
#| label: calculate-m3-critical-value

power_alpha_m3 <- 0.05

critical_value_m3 <- unname(
  quantile(
    bootstrap_max_statistic_m3,
    probs = 1 - power_alpha_m3
  )
)

  bootstrap_max_statistic_m3 >=
    critical_value_m3
)

  有意水準 = power_alpha_m3,
  帰無分布simulation数 = length(
    bootstrap_max_statistic_m3
  ),
  棄却臨界値 = critical_value_m3,
  帰無simulationで臨界値以上となった割合 =
    empirical_null_rejection_m3
)

critical_value_summary_m3 %>%
  mutate(
    across(
      c(
        有意水準,
        帰無simulationで臨界値以上となった割合
      ),
      ~ scales::percent(

      )
    )
  ) %>%
  knitr::kable(
    digits = 4
  )
```

各simulationで得た最大尤度比統計量を $T_{\max}$ とし、

$$
T_{\max}\geq c_\alpha
$$

なら変化を検出できたと判定する。

## 共通の検出力simulation関数

第2段階の `calculate_max_m1_m3_statistic()` をそのまま検定統計量の計算に使用する。

```{r}
#| label: define-m3-power-function

power_simulation_repetitions_m3 <- 5000L

estimate_m3_detection_power <- function(
  p1,
  p2,
  true_daily_position,
  repetitions,
  simulation_seed
) {
  stopifnot(
    p1 >= 0,
    p1 <= 1,
    p2 >= 0,
    p2 <= 1,
    true_daily_position >= 1,
    true_daily_position < nrow(daily_slot2)
  )

  true_probability_by_day <- if_else(
    seq_len(nrow(daily_slot2)) <=
      true_daily_position,
    p1,
    p2
  )

  set.seed(simulation_seed)

  simulated_max_statistic <- map_dbl(
    seq_len(repetitions),
    function(i) {
      simulated_a_count <- rbinom(
        n = nrow(daily_slot2),
        size = daily_slot2$試行数,
        prob = true_probability_by_day
      )

      calculate_max_m1_m3_statistic(
        a_count = simulated_a_count
      )
    }
  )

  detected <- simulated_max_statistic >=
    critical_value_m3

  estimated_power <- mean(detected)

  tibble(
    p1 = p1,
    p2 = p2,
    真の変化点日次位置 = true_daily_position,
    simulation回数 = repetitions,
    検出成功回数 = sum(detected),
    推定検出力 = estimated_power,
    Monte_Carlo標準誤差 = sqrt(
      estimated_power *
        (1 - estimated_power) /
        repetitions
    ),
    simulation_seed = simulation_seed
  )
}
```

ここで示すMonte Carlo標準誤差は、指定した臨界値のもとで行う代替モデル側の
5,000反復に由来する誤差である。
2,000反復の帰無simulationから臨界値を推定したことによる不確実性は含まない。

# 補足：Part 1の通説値との比較

本記事の主分析では一定モデル $M_1$ を基準としたが、
Part 1との接続を確認するため、通説値 $p=1/3$ に固定したモデル $M_0$ との比較も示す。

$$
M_0: A_d \sim \operatorname{Binomial}\left(n_d,\frac{1}{3}\right)
$$

## 通説値と一定モデルの比較

```{r}
#| label: fit-part1-reference-model

log_lik_m0 <- daily_binomial_log_lik(
  data = daily_slot2,
  prob = 1 / 3
)

lr_m0_m1 <- 2 * (
  log_lik_m1 - log_lik_m0
)

p_lr_m0_m1 <- pchisq(
  lr_m0_m1,
  df = 1,
  lower.tail = FALSE
)

binom_m0 <- binom.test(
  x = x_slot2_A,
  n = n_slot2,
  p = 1 / 3,
  alternative = "two.sided"
)

# 全試行を1個のBinomial観測として集約した場合とも比較する。
# 絶対的な対数尤度は二項係数が異なるため一致しないが、
# M0とM1の尤度比ではその差が相殺される。
p_m1_all_in_one <- x_slot2_A / n_slot2

log_lik_m0_all_in_one <- dbinom(
  x = x_slot2_A,
  size = n_slot2,
  prob = 1 / 3,
  log = TRUE
)

log_lik_m1_all_in_one <- dbinom(
  x = x_slot2_A,
  size = n_slot2,
  prob = p_m1_all_in_one,
  log = TRUE
)

lr_m0_m1_all_in_one <- 2 * (
  log_lik_m1_all_in_one -
    log_lik_m0_all_in_one
)

binom_m0_from_daily_totals <- binom.test(
  x = sum(daily_slot2$A出現数),
  n = sum(daily_slot2$試行数),
  p = 1 / 3,
  alternative = "two.sided"
)

stopifnot(
  isTRUE(
    all.equal(
      p_m1,
      p_m1_all_in_one,
      tolerance = 1e-12
    )
  ),
  isTRUE(
    all.equal(
      binom_m0$p.value,
      binom_m0_from_daily_totals$p.value,
      tolerance = 1e-12
    )
  ),
  isTRUE(
    all.equal(
      lr_m0_m1,
      lr_m0_m1_all_in_one,
      tolerance = 1e-10
    )
  )
)
```


Binomial観測のまとめ方を変えると、二項係数が変わるため、
$M_0$ と $M_1$ それぞれの絶対的な対数尤度は変化する。
一方、同じ集約単位で計算した2モデル間の尤度比では二項係数が相殺される。
そのため、$M_1$ の推定確率、正確二項検定、尤度比統計量は変わらない。
