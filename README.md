# Pokémon Sleep 食材パターン分析

Pokémon Sleep の食材パターンについて、
個人で収集したデータを用いて出現確率や時間依存性を調べるプロジェクト。

分析は R / Quarto で行い、
分析結果をもとに note 向けの記事を作成する。

## 分析ファイル

### `analysis/01_probability.qmd`

食材パターンの累積的な出現確率について調べる。

主な問い：

- 6パターンの比率は通説上の 1:1:1:2:2:2 と整合するか
- 2枠目の A:B は 1:2 と整合するか
- 3枠目の A:B:C は 1:1:1 と整合するか
- 2枠目と3枠目は独立とみなせるか
- 各確率はどの程度と推定されるか

頻度論的な検定に加え、
Dirichlet分布・Beta分布を用いたベイズ推定も行う。

現在の第1記事に対応する分析。

### `analysis/02_slot2_time.qmd`

2枠目Aの出現確率の時間変化を調べる。

`01_probability.qmd` では、
全期間をまとめると2枠目Aの出現割合が通説上の 1/3 より低いという結果が得られた。

一方、時系列で見ると、
初期から一貫して低かったわけではなく、
ある時期以降にAが出にくくなったようにも見える。

そこで、

- 出現確率は時間を通じて一定なのか
- 一定なら、その確率は 1/3 なのか、それより低いのか
- 時間とともに滑らかに変化しているのか
- ある時点を境に変化した可能性があるのか
- 見かけ上の変化が固定確率モデルのランダムな揺らぎで説明できるのか

を調べる。

### `analysis/archive/`

## 今後の記事候補

### AAA

ゲーム上特に関心の高い AAA パターンに絞って時間推移を調べる。

特に、

\[
P(AAA)
=
P(\text{2枠目}=A)
P(\text{3枠目}=A\mid\text{2枠目}=A)
\]

と分解し、
AAAの増減がどの要素によって生じているかを見る。

### ランダム性・履歴依存性

各抽選が独立な固定確率のランダム抽選とみなせるかを調べる。

候補となるテーマ：

- 累積偏差
- 過分散・過小分散
- 週単位の変動
- ラグ依存
- 帳尻合わせ・バランシング
- 有限記憶モデル

## データ

元データは Google Sheets 上で継続的に更新している。

主なデータフレーム：

- `df_org`: 読み込んだ元データ
- `df`: 収集開始後かつ3食材種のみ
- `df2`: 収集開始後。2枠目の分析では2食材種も含める

したがって、
2枠目の分析と3枠目・6パターンの分析では
サンプルサイズが異なる場合がある。
