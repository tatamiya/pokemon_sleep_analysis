# 公開用データ

`ingredient_patterns_2025-11-16_2026-09-05.csv` は、
Part 1・Part 2で使用したデータを固定したスナップショットです。

## 収録範囲

- 観測期間：2025-11-16〜2026-09-05
- 観測数：360個体
- 2食材種：7個体
- 3食材種：353個体
- 収集開始前の記録は除外済み
- ポケモン名を収録
- 色違いなど、公開分析に不要な情報は含めない

## 列

| 列 | 内容 |
|---|---|
| `日付` | 個体を記録した日付 |
| `ポケモン名` | 記録したポケモンの名前（例：ピチュー、ピカチュウ、ライチュウ） |
| `食材種数` | 2食材種または3食材種 |
| `食材パターン` | AAA・AAB・AAC・ABA・ABB・ABC |
| `2枠目` | AまたはB |
| `3枠目` | A・B・Cのいずれか |

1行が1個体に対応します。
2食材種の個体についても、ゲーム画面で確認できる3枠目までの食材パターンを記録しています。
Part 1の3枠目および6パターンの分析では3食材種だけを使用し、
2枠目の分析では2食材種も含めます。

## 更新

記事の再現には、この固定CSVを使用します。
Google Sheets上の継続記録からスナップショットを作り直す場合は、
環境変数 `POKEMON_SLEEP_SHEET_URL` にシートURLを設定したうえで、
プロジェクトのルートから次を実行します。

```sh
Rscript scripts/update_data_snapshot.R
```

スナップショットを更新した場合は、分析結果と記事中の数値も再確認します。
